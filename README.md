# 🚀 CareerLaunch AI

CareerLaunch AI is an AI-powered placement preparation platform that helps students improve their interview performance and resume quality. It combines AI-driven resume analysis, ATS scoring, mock interviews, and progress tracking into one easy-to-use web application.

---

## ✨ Features

### 🔐 User Authentication
- User Registration & Login
- Secure Session Management

### 📄 AI Resume Analyzer
- Upload PDF or DOCX resumes
- AI-powered resume analysis
- ATS Score Generation
- Resume improvement suggestions
- Resume history

### 🎤 AI Mock Interview
- Resume-based interview
- Interview without resume
- Role and skill selection
- AI-generated interview questions
- AI evaluation and feedback
- Interview history

### 📊 Dashboard
- Placement Readiness Score
- Recent Activity
- Interview Performance
- Resume Analysis History
- AI Recommendations

### 🎨 Modern UI
- Responsive Landing Page
- Interactive Dashboard
- Clean & User-Friendly Design

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/CareerLaunch-AI.git
```

### 2. Navigate to the Project Folder

```bash
cd CareerLaunch-AI
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

Windows

```bash
venv\Scripts\activate
```

macOS/Linux

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Environment Variables

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

### 7. Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
